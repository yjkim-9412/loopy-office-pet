# 루피펫 이미지 요청서 (코덱스용)

## 코덱스에 이렇게 보내 주세요

```text
docs/design/codex-image-requests.md 를 읽고, "요청 목록"의 "추가 요청"부터 차례로 루피 이미지를 만들어 줘.
1~3순위와 정지 이미지는 이미 incoming/에 있으니 다시 만들지 않아도 돼.
모든 이미지는 이 문서의 "레퍼런스 기반 생성 규칙"을 지켜야 하고, 레퍼런스 이미지 3개를 반드시 보고 그려.
만든 그림은 incoming/<파일 이름>.png 로 저장해 줘. assets/ 폴더는 건드리지 마.
```

## 레퍼런스 기반 생성 규칙

루피의 얼굴과 크기가 이미지마다 달라지지 않도록, 매번 아래 레퍼런스를 보고 그립니다. 글로만 설명해서 새로 그리지 않습니다.

| 레퍼런스 | 보는 이유 |
|---|---|
| `assets/brand/icon.png` | 정면 기본형. 얼굴 비율, 털 색, 볼터치, 자두색 코, 앞니 두 개, 주황 깃털 세 가닥 |
| `docs/design/reference/loopy-reference.png` | 앱 안의 실제 크기로 맞춘 8가지 자세. 서 있을 때와 앉았을 때 머리 크기가 같은 것을 확인 |
| `docs/design/reference/frame-template-4x2.png` | 512×512 칸 8개. 빨간 선은 발끝 바닥선, 파란 점선은 서 있을 때 머리 끝, 초록 선 사이는 머리 폭 |

1. **같은 캐릭터:** 레퍼런스와 같은 얼굴 비율, 눈 간격, 코와 이빨 모양, 털 질감, 색, 조명, 3D 렌더 느낌을 유지합니다. 다른 캐릭터처럼 보이면 다시 만듭니다.
2. **같은 크기:** 512px 칸 기준 머리 폭(귀 제외, 볼 높이)은 약 222px입니다. 서 있으면 머리 끝이 y≈42, 발끝이 y≈482입니다. 앉거나 숙이거나 누워도 머리 크기는 그대로 두고, 칸을 채우려고 몸을 키우지 않습니다.
3. **같은 바닥:** 모든 프레임의 발끝(앉은 자세는 엉덩이와 발)을 바닥선 y≈482에 맞춥니다. 점프 프레임만 위로 뜹니다.
4. **깨끗한 배경:** 완전 투명한 PNG입니다. 글자, 가이드 선, 바닥 그림자, 배경 무늬는 넣지 않습니다. 캐릭터와 목록에 적힌 소품만 그립니다.
5. **촘촘한 모션:** 모션 하나는 8프레임입니다. 템플릿처럼 4열×2행(2048×1024)에 왼쪽에서 오른쪽, 위에서 아래 순서로 놓습니다. 이웃한 프레임은 조금씩만 달라지게 하고, 8번에서 1번으로 자연스럽게 이어지게 합니다.
6. **팔다리 개수:** 모든 프레임에서 팔은 두 개, 다리는 두 개입니다. 옆모습에서는 뒤쪽 팔이 몸에 가려지거나 손끝만 살짝 보이게 하고, 배 앞에 세 번째 팔이나 손이 생기지 않았는지 프레임마다 확인합니다. 생겼으면 그 프레임만 다시 만듭니다.
7. **눈:** 루피 눈은 흰자가 없는 까만 구슬에 작은 하이라이트만 있습니다. 곁눈질이나 놀란 눈에서도 흰자를 그리지 않고, 까만 눈의 위치와 크기만 바꿉니다.

매 요청 앞에 아래 문단을 붙입니다.

```text
첨부한 레퍼런스 assets/brand/icon.png 와 docs/design/reference/loopy-reference.png 의 루피와 똑같은 캐릭터를 그려 줘.
얼굴 비율, 털 색과 질감, 자두색 코, 앞니, 주황 깃털 세 가닥, 3D 렌더 조명을 그대로 유지해.
docs/design/reference/frame-template-4x2.png 처럼 512×512 칸 8개(4열×2행, 2048×1024)에 8프레임을 순서대로 그려.
머리 폭(귀 제외)은 약 222px, 발끝은 칸마다 y=482 선에 맞추고, 앉거나 숙여도 머리 크기는 바꾸지 마.
배경은 완전 투명, 글자·가이드 선·그림자 없이 캐릭터와 말한 소품만.
```

## 요청 목록

### 새 요청 — 점심 뒤 아이스 아메리카노 (8프레임, `incoming/iced.png`)

점심시간 알림을 켜 두면 점심이 끝날 때 루피가 "밥 먹었으면 아아뤂! 아아 아니면 안 된뤂!" 같은 말을 합니다. 앱에 `iced`라는 이름이 이미 연결되어 있어서, 그림이 들어오면 지금 대신 쓰는 커피(`coffee`, 뜨거운 머그컵) 자리에 바로 나옵니다.

| 이름 | 언제 나오나 | 지금 대신 쓰는 모션 | 8프레임 내용 |
|---|---|---|---|
| `iced` | 점심이 끝났을 때 | 커피 한 모금(`coffee`) | 얼음이 가득 든 투명 플라스틱 컵의 아이스 아메리카노(진한 갈색, 빨대 하나)를 두 손으로 들고 → 빨대로 쭉쭉 → 눈을 꼭 감고 볼이 빨개지며 "캬~" 하는 행복한 표정 → 컵을 살짝 흔들어 얼음이 찰랑 → 컵을 볼에 대고 시원해하며 미소. 컵에 글자나 로고는 넣지 말고, 서 있는 자세로 발은 바닥선에 |

받은 뒤에는 `python scripts/import_sprites.py incoming/iced.png iced --cols 4 --rows 2 --template`으로 넣고, `assets/motions.json`에 `"iced": {"label": "아아 한 잔", ...}`을 다른 8프레임 모션처럼 등록합니다.

### 새 요청 — 야근 (8프레임, `incoming/<이름>.png`)

퇴근 시각 30분 뒤에도 컴퓨터를 쓰고 있으면 루피가 "설마… 야근이뤂?" 하고 묻고, 야근이라고 하면 "야근이라니… 루피 눈물 나뤂!" 하며 옆에서 같이 있어 줍니다. 앱에 아래 이름이 이미 연결되어 있어서, 그림이 들어오면 지금 대신 쓰는 모션 자리에 바로 나옵니다. 네 모션 모두 서 있거나 앉은 자세라 발(앉은 자세는 엉덩이)이 바닥선에 닿게 그립니다.

| 이름 | 언제 나오나 | 지금 대신 쓰는 모션 | 8프레임 내용 |
|---|---|---|---|
| `suspicious` | "설마… 야근이뤂?", "아직 있뤂?", 야근 중 한 시간마다 확인할 때 | 퇴근 기다리기(`clock`) | 손목시계를 한 번 보고 → 눈을 가늘게 뜨고 화면 쪽을 빤히 → 몸을 앞으로 살짝 기울이며 턱을 괴고 의심 가득 → 한쪽 눈썹을 올리고 "설마…" 하는 표정 → 다시 시계를 톡톡 |
| `shock` | "응… 야근이야"라고 대답했을 때 | 빙글빙글 어지러움(`dizzy`) | 입이 쩍 벌어지고 눈이 동그래짐 → 두 손으로 볼을 감싸 쥐기 → 눈가에 눈물이 맺히고 작은 눈물방울이 톡 → 훌쩍 → 주먹을 꼭 쥐고 "그래도 같이 있을게" 하는 결연한 끄덕 |
| `overtime` | 야근 중 옆에서 같이 있을 때(평소 대기 대신) | 집중 타이핑(`typing`) | 받은 `typing`과 같은 작은 노트북 앞에 앉아, 졸린 눈으로 느릿느릿 타이핑 → 꾸벅 졸다가 화들짝 → 양손으로 볼을 톡톡 치며 정신 차리기 → 작은 머그컵 한 모금 → 다시 타이핑. 반복 재생되니 8번에서 1번으로 자연스럽게 이어지게 |
| `freed` | "이제 퇴근할게"를 눌렀을 때 | 업무 완료 만세(`celebrate`) | 받은 `pack`과 같은 작은 갈색 가방을 번쩍 들어 메고 → 두 팔 만세로 폴짝 점프 → 착지하며 신나서 제자리 총총 → 손 크게 흔들며 "드디어 퇴근!" 하는 함박웃음 |

받은 뒤에는 이름마다 `python scripts/import_sprites.py incoming/<이름>.png <이름> --cols 4 --rows 2 --template`으로 넣고 `assets/motions.json`에 등록합니다(라벨 예: 설마 야근?, 야근이라니, 야근 동행, 드디어 퇴근).

### 추가 요청 — 산책 · 업무 앱 반응 · 창 위에 앉기 (8프레임, `incoming/<이름>.png`)

> 11월 23일에 `bored`, `fall`, `sit`, `look`, `perch`를 받아서 앱에 넣었습니다. 다시 그린 `walk`는 첫 번째 걷기가 더 좋아서 쓰지 않았습니다.

1~3순위와 정지 이미지는 11월 23일에 `incoming/`으로 모두 받았습니다. 그 뒤에 들어간 기능(루피 산책, 업무 앱을 오래 쓸 때의 지루함, 파일 탐색기 창 위에 앉기)이 쓰는 모션입니다. 앱에 이 이름들이 이미 연결되어 있어서, 그림이 들어오면 지금 대신 쓰는 모션 자리에 바로 나옵니다.

| 이름 | 언제 나오나 | 지금 대신 쓰는 모션 | 8프레임 내용 |
|---|---|---|---|
| `bored` | 엑셀·구글 스프레드시트 같은 업무 앱을 오래 붙잡고 있을 때 지루함을 말할 때 | 퇴근 기다리기(`clock`) | 앉아서 한 손으로 턱 괴기 → 눈이 반쯤 감기며 한숨(작은 입김) → 몸이 옆으로 축 늘어짐 → 하품 → 고개를 털고 다시 정신 차리기 |
| `fall` | 산책 중 공중에 놓였거나 내려놓은 자리가 공중이라 바닥으로 떨어질 때 | 대롱대롱(`held`) | 팔다리를 쫙 벌리고 낙하, 볼과 깃털이 바람에 위로 펄럭, 놀라 동그래진 눈 → 땅이 가까워지며 몸을 웅크리기. 공중 자세라 발이 바닥선에 닿지 않아도 되고 머리 크기는 그대로 |
| `sit` | 산책하다 멈춰서 쉴 때(근무 시간의 평소 대기 대신) | 멍때리기(`idle`) | 바닥에 털썩 앉기 → 다리를 앞뒤로 달랑달랑 → 주위를 둘러보기 → 눈 깜빡. 엉덩이와 발이 바닥선에 닿게 |
| `look` | 산책 중 도착한 곳을 구경하며 한마디 할 때 | 그때의 대기 모션 | 한 손을 이마에 대고 왼쪽 → 오른쪽 두리번 → 무언가 발견한 듯 눈 반짝 → 고개 끄덕 |
| `walk` | 산책하거나 탐색기 창 위를 걸을 때 | — | 2·3번을 팔 두 개로 고친 그림(`incoming/walk-fixed.png`)을 받아 8프레임 모두 씁니다. 추가 요청 없음 |
| `idle` | 근무 시간에 가만히 서 있을 때 | — | 4·6번 눈 흰자를 고친 그림(`incoming/idle-fixed2.png`)을 받아 8프레임 모두 씁니다. 추가 요청 없음 |
| `perch` | 파일 탐색기 창 윗변에 앉아 있을 때 | 그때의 대기 모션 | 창 모서리에 걸터앉아 다리를 아래로 늘어뜨리고 달랑달랑, 창 아래를 내려다보기, 손으로 모서리를 톡톡. 엉덩이가 바닥선(창 윗변)에 오게 그리고 다리는 바닥선 아래로 내려와도 됩니다 |

`stretch`(3순위로 받은 그림)는 이제 같은 업무 앱을 50분 넘게 쓸 때 기지개를 권하는 모션으로도 씁니다.

### 1순위 — 새 상호작용 모션 (8프레임, `incoming/<이름>.png`)

앱에 이미 동작이 들어가 있어서, 그림만 넣으면 바로 이 모션으로 바뀝니다. 지금은 비슷한 기존 모션으로 대신 보여 줍니다.

드래그는 상태마다 모션이 다릅니다. 드래그 모션 다섯 개는 모두 공중에 들린 자세라 발이 바닥선에 닿지 않아도 되지만, 머리 크기와 칸 가운데 위치는 다른 모션과 같게 둡니다.

| 이름 | 언제 나오나 | 8프레임 내용 |
|---|---|---|
| `grab` | 루피를 막 집어 들었을 때(처음 0.35초) | 정수리 털을 잡혀 쏙 들리며 깜짝 → 눈 동그랗게 → 팔다리 움찔 |
| `held` | 들고만 있고 마우스를 움직이지 않을 때 | 공중에 매달려 대롱대롱 흔들림, 다리를 천천히 앞뒤로, 심심한 표정과 눈 깜빡 |
| `drag` | 들고 끌고 갈 때 | 오른쪽을 보는 옆모습으로 끌려가며 다리 버둥버둥, 몸이 진행 반대쪽으로 살짝 기울고 신난 표정. 왼쪽으로 갈 때는 앱이 좌우를 뒤집습니다 |
| `dizzy` | 좌우로 마구 흔들 때 | 눈이 빙글빙글(소용돌이 눈), 머리 위로 작은 별, 몸이 축 늘어졌다가 고개를 휘휘 |
| `aim` | 파일 탐색기 창 윗변처럼 앉을 수 있는 자리 위에 왔을 때 | 아래를 내려다보며 발끝을 쭉 내밀기, 눈 반짝, 엉덩이를 살짝 흔들며 "여기!" 하는 설렘 |
| `land` | 원하는 자리나 파일 탐색기 위에 내려놓을 때 | 살짝 떠 있다가 쿵 착지 → 무릎 굽혀 흡수 → 펴면서 손 털기 → 뿌듯한 표정 |
| `poke` | 루피를 더블클릭할 때 | 찔린 볼을 감싸며 움찔 → 째려보기 → 입 삐죽 → 장난스럽게 씩 웃기 |
| `pat` | 마우스로 루피 위를 좌우로 문지를 때 | 눈 감고 머리를 기울이며 행복 → 볼이 더 빨개짐 → 몸을 좌우로 살랑 → 하트 대신 반짝이는 눈웃음 |

지금은 4프레임이라 움직임이 뚝뚝 끊깁니다. 같은 동작을 8프레임으로 다시 그립니다.

|---|---|
| `idle` | 제자리에서 숨쉬기(배가 살짝 오르내림), 눈 깜빡, 두리번 |
| `walk` | 옆모습으로 총총 걷기 한 걸음 주기, 마지막에 작은 깡총 |
| `wave` | 한 손 인사를 크게 두 번, 반대 손으로 한 번 |
| `typing` | 작은 노트북 앞에 앉아 양손 번갈아 타이핑, 화면 보며 끄덕 |
| `celebrate` | 웅크렸다가 만세 점프, 착지 후 박수 |

| `doze` | 앉은 채 꾸벅꾸벅 졸다가 화들짝 깨기 |

### 3순위 — 루틴 모션 (8프레임)

## 받은 그림을 앱에 넣는 법

모션(8프레임, 4열×2행):

```sh
python scripts/import_sprites.py incoming/held.png held --cols 4 --rows 2 --template
python scripts/hitmaps.py
```

템플릿(512px 칸)에 맞춰 그린 그림은 `--template`로 넣습니다. 칸을 256px로 줄이기만 하고 그린 크기와 위치를 그대로 두므로, 템플릿으로 그린 모든 모션이 같은 크기가 되고 공중 자세는 공중에 남습니다. 2026-11-23에 받은 26개 모션은 모두 이 방식으로 넣었고, 머리 폭이 기준 루피의 0.96~1.01배 안에 들어왔습니다. 템플릿 없이 그린 그림만 아래처럼 머리 폭 맞춤으로 넣습니다.

```sh
python scripts/import_sprites.py incoming/old-grid.png todo filing
```

가져오기 도구가 배경의 잔여물을 지우고, 머리 폭을 기준 루피(`assets/motions/idle.png`)에 맞춰 크기를 통일하고, 발을 같은 바닥선에 놓습니다. 그다음 `assets/motions.json`에 `"frames": 8`과 재생 순서를 적고 `npm test`를 돌립니다. 테스트는 모든 모션의 머리 크기가 기준과 ±15% 안인지, 발이 같은 선에 있는지 확인합니다. 옆모습처럼 머리 폭을 재기 어려운 자세는 `--scale 0.5`처럼 배율을 직접 줍니다.

앱이 자동으로 찾아 쓰는 모션 이름은 `grab`, `held`, `drag`, `dizzy`, `aim`, `land`, `poke`, `pat`, `bored`, `stretch`, `fall`, `sit`, `look`, `perch`입니다. `assets/motions.json`에 이 이름으로 등록하면 대신 쓰던 모션 자리에 바로 나옵니다. 공중에 뜬 자세(`held`, `drag`, `dizzy`, `aim`, `fall`)는 `"airborne": true`, 몸 일부만 보이는 자세(`peek`)는 `"partial": true`, 다리를 바닥선 아래로 늘어뜨리는 자세(`perch`)는 `"hangs": true`를 함께 적어야 크기·바닥선 테스트를 통과합니다.

정지 이미지는 `assets/ui/<이름>.png`로 옮기면 수첩 화면이 기존 모션 프레임 대신 바로 불러 씁니다.
