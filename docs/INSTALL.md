# 루피의 업무 수첩 설치 안내

개발 도구 없이 파일 하나만 받아서 설치할 수 있어요. 개인 비상업용 팬 제작물이라 공개된 곳에 올리거나 판매하지 않아요(`LICENSE`, README의 "저작권과 이용 지침").

## 어떤 파일을 받나요

| 내 컴퓨터 | 받을 파일 | 특징 |
|---|---|---|
| Windows (대부분의 PC) | `LoopyOffice-Setup-<버전>-x64.exe` | 두 번 누르면 설치되고 바로 실행돼요. 바탕화면과 시작 메뉴에 바로가기가 생겨요 |
| Windows, 설치하기 곤란할 때 | `LoopyOffice-Portable-<버전>-x64.exe` | 설치 없이 그 파일을 눌러서 바로 써요. USB에 넣어 다녀도 돼요 |
| Mac (M1·M2·M3·M4 등 애플 칩) | `LoopyOffice-<버전>-mac-arm64.dmg` | 화면 왼쪽 위 사과 메뉴 › 이 Mac에 관하여에서 "칩: Apple M…"이면 이것 |
| Mac (인텔 칩) | `LoopyOffice-<버전>-mac-x64.dmg` | "프로세서: Intel…"이면 이것 |

파일은 GitHub 저장소의 **Actions › Build desktop**에서 가장 최근 성공한 실행을 열고, 아래쪽 **Artifacts**에서 내 컴퓨터에 맞는 묶음을 받아 압축을 풀면 나와요. 저장소 접근 권한이 있어야 해요.

## Windows

1. `LoopyOffice-Setup-…-x64.exe`를 두 번 눌러요.
2. 파란 창으로 **"Windows의 PC 보호"**가 뜨면 **추가 정보**를 누르고 **실행**을 눌러요. 회사 인증서로 서명하지 않은 개인 앱이라 처음 한 번 뜨는 안내예요.
3. 따로 묻는 화면 없이 설치가 끝나고 루피가 화면 오른쪽 아래에 나타나요. 관리자 권한은 필요 없어요.
4. 처음 만나면 루피가 말풍선으로 이름과 출퇴근 시간 등을 물어봐요. 나중에 할래를 눌러도 돼요.

- **다시 열기:** 바탕화면이나 시작 메뉴의 **Loopy Office**를 눌러요. 작업 표시줄 오른쪽 숨김 아이콘(^)에서 루피 아이콘을 오른쪽 클릭해도 메뉴가 나와요.
- **컴퓨터를 켤 때마다 실행:** 처음 실행할 때 자동으로 켜져서, 컴퓨터를 켜면 루피도 같이 나타나요. 원하지 않으면 수첩 › 설정 › 시작 프로그램에서 "로그인할 때 루피 실행"을 끄면 되고, 끈 설정은 그대로 유지돼요.
- **새 버전으로 바꾸기:** 0.2.0부터는 루피가 알아서 바꿔요(아래 "새 버전"). 새 설치 파일을 직접 실행해도 덮어써지고, 할 일과 설정은 남아 있어요.
- **지우기:** Windows 설정 › 앱 › 설치된 앱에서 Loopy Office를 제거해요. 할 일과 설정 파일(`%APPDATA%\Loopy Office`)은 남겨 두니, 완전히 지우려면 그 폴더도 지워요.

## Mac

1. 내 칩에 맞는 `.dmg`를 두 번 눌러 열고, Loopy Office 아이콘을 응용 프로그램 폴더로 끌어다 놓아요.
2. 응용 프로그램 폴더에서 Loopy Office를 **오른쪽 클릭(또는 control+클릭) › 열기**를 누르고, 다시 묻는 창에서 **열기**를 눌러요. 애플 인증을 받지 않은 개인 앱이라 처음 한 번만 이렇게 열어요.
3. "열 수 없습니다"라고만 나오면 **시스템 설정 › 개인정보 보호 및 보안**을 열어 아래쪽의 **그래도 열기**를 눌러요.
4. 처음 만나면 루피가 말풍선으로 몇 가지를 물어봐요.

- **로그인할 때 실행:** 처음 실행할 때 자동으로 켜져요. 끄려면 수첩 › 설정 › 시작 프로그램에서 꺼요.
- **지우기:** 응용 프로그램 폴더의 Loopy Office를 휴지통으로 옮겨요. 할 일과 설정은 `~/Library/Application Support/loopy-office-pet`에 남아 있어요.

## 새 버전

- **Windows(설치한 버전):** 루피가 켜진 지 1분 뒤와 그 뒤 6시간마다 새 버전이 있는지 확인해요. 있으면 조용히 받아 두고 "새 버전 … 도착이뤂!" 하고 물어봐요.
  - **지금 바꾸기**를 누르면 잠깐 꺼졌다가 새 버전으로 다시 켜져요.
  - **나중에**를 누르면 다음에 루피를 끌 때 바뀌어요. 작업 표시줄 오른쪽(^)의 루피 아이콘 메뉴에 있는 **새 버전으로 다시 시작**으로도 바꿀 수 있어요.
  - 할 일과 설정은 그대로 남아요.
- **Windows 포터블, Mac:** 스스로 바꿀 수 없어서, 새 버전이 나오면 루피가 알려 주기만 해요. 보내 준 사람에게 새 파일을 받아 설치해요.
- 업데이트 기능은 0.2.0부터 들어 있어요. 0.1.0을 쓰고 있다면 0.2.0 이상을 한 번만 직접 설치해 주세요.

## 알아 두면 좋은 것

- 루피는 파일 이름, 폴더 이름, 화면 내용을 읽지 않아요. 할 일과 설정은 내 컴퓨터에만 저장돼요. 새 버전을 확인할 때만 업데이트 저장소에 접속하고, 그때 내 정보나 할 일은 보내지 않아요. 업무 앱 알아보기(Windows)를 끄면 맨 앞 창의 프로그램 이름도 보지 않아요.
- 두 대의 컴퓨터에 설치하면 할 일은 컴퓨터마다 따로 관리돼요.
- 루피를 잠깐 치우고 싶으면 루피를 오른쪽 클릭 › 루피 숨기기, 다시 보려면 트레이 아이콘 › 루피 보여주기예요.
