# 루피의 업무 수첩

Windows와 macOS에서 쓰는 개인용 Electron 데스크톱 펫입니다. 루피를 누르면 루피가 말풍선으로 "뭐 도와줄까뤂?" 하고 묻고, 할 일 적기·오늘 할 일 체크·수첩 열기·알림 쉬기를 말풍선에서 바로 할 수 있습니다. 루피 주변의 투명한 여백을 클릭하면 아래 창으로 입력이 전달됩니다.

처음 실행하면 루피가 말풍선으로 부를 이름, 출퇴근 시각, 근무 요일, 점심시간, 말투(잔망·다정·차분), 수다 레벨(조용히·적당히·수다쟁이)을 차례로 묻습니다. 수첩의 **나만의 루피**에서 언제든 바꾸거나 루피에게 다시 소개할 수 있습니다. 수첩은 **오늘**(할 일·도장판), **내 루틴**, **나만의 루피**(말투·근무 일정·행동·기본 자리·모션 미리보기) 세 탭과 퇴근 리포트로 나뉩니다. 퇴근 리포트에는 오늘 해낸 일, 남은 일(내일로 옮기기), 칭찬 도장, 이번 주 도장판이 나옵니다.

## 설치 (일반 사용자)

개발 도구 없이 설치 파일 하나로 쓸 수 있어요. 최신 설치 파일은 [Releases](https://github.com/yjkim-9412/loopy-office-pet/releases/latest)에서 받아요. 받을 파일과 설치 순서, Windows·Mac에서 처음 한 번 뜨는 보안 안내를 넘기는 방법은 [docs/INSTALL.md](docs/INSTALL.md)에 정리했어요. Windows는 클릭 한 번으로 설치되는 설치 파일과 설치 없이 쓰는 포터블 파일을 함께 만들어요.

## 실행

Node.js 22 이상을 사용합니다. Windows 개발 환경에는 .NET Framework 4 C# 컴파일러, macOS에는 Xcode Command Line Tools가 필요합니다. 설치본에는 운영체제별 창 감지 도우미가 포함됩니다.

```sh
npm install
npm test
npm start
```

Windows에서 `npm run dist:win`을 실행하면 NSIS 설치 프로그램을, Mac에서 `npm run dist:mac`을 실행하면 현재 아키텍처용 DMG를 `release/`에 만듭니다. GitHub Actions의 **Build desktop**은 Windows x64, Mac Apple Silicon, Mac Intel 패키지를 각각 만듭니다. 개인용 빌드에는 배포용 개발자 서명과 Apple 공증을 설정하지 않았습니다.

## 업데이트와 새 버전 내기

- **받는 쪽(`app/update.cjs`):** 설치한 Windows 앱은 시작 1분 뒤와 6시간마다 이 저장소의 공개 GitHub Releases를 확인하고, electron-updater로 새 버전을 받아 두었다가 루피 말풍선의 "지금 바꾸기", 수첩의 **지금 업데이트하기**, 트레이 메뉴, 또는 앱을 끌 때 설치합니다. 받는 동안과 받은 뒤에는 수첩 위쪽에 업데이트 버튼이 떠서 받는 정도와 업데이트 안내를 보여 줍니다. 포터블과 Mac은 스스로 바꿀 수 없어서(Mac은 개발자 서명이 필요) 최신 릴리스의 `latest.yml`만 읽고, 새 버전이 있다고 말하며 수첩의 업데이트 버튼과 트레이 메뉴에서 새 파일을 받는 순서를 안내합니다. 수첩 › 나만의 루피의 **앱 업데이트**에서 지금 버전을 보고 바로 확인할 수도 있습니다. 공개 저장소라 키나 토큰이 필요 없습니다.
- **올리는 쪽(`scripts/release.cjs`):** main에 push된 빌드가 Windows·Mac 모두 성공하면 `release` 작업이 설치본 네 개(Setup, Portable, Mac 두 종), Setup 블록맵, `latest.yml`을 `v<버전>` 릴리스로 올립니다. 이미 릴리스된 버전이거나 최신 릴리스보다 새 버전이 아니면 아무것도 하지 않습니다. 손으로 돌린 빌드(workflow_dispatch)와 브랜치 빌드는 릴리스하지 않습니다.
- **새 버전 내기:** `package.json`의 `version`을 올려서 main에 머지하면 됩니다. 버전을 올리지 않은 머지는 릴리스되지 않습니다.

## 하루의 행동

기본 근무 시간은 월~금 09:00~18:00입니다. 설정에서 근무 요일과 출퇴근 시각을 바꿀 수 있습니다. 자정을 넘는 근무는 출근한 요일을 기준으로 계산합니다.

| 시점 또는 조작 | 루피의 행동 |
|---|---|
| 출근 후 30분 안에 첫 실행 | 오늘 적은 TODO가 없으면 수첩을 들고 “오늘 TODO는 작성했어뤂?” 하고 묻습니다. 말풍선에서 바로 적거나, 어제 남은 일을 가져오거나, 넘길 수 있습니다. 이미 작성했다면 손인사합니다. |
| 늦게 출근한 날 | 아침 확인을 건너뛰었다면 근무 중 다음 정각에 한 번만 TODO를 묻습니다. |
| 근무 중 정각 | 수다 레벨에 따라 매 정각(수다쟁이) 또는 두 시간마다(적당히) 타이핑·커피·서류 정리·메모 동작을 바꿉니다. 조용히에서는 쉬어요. 지난 시간의 알림은 한꺼번에 보내지 않습니다. |
| 점심시간(켠 경우) | 점심 시작에 인사하고 점심 동안은 조용히 있다가, 끝나면 꾸벅 좁니다. |

| 퇴근 15분 전 (10·15·30분 중 선택) | 남은 TODO 수를 알려 주며 서류를 정리합니다. 말풍선의 **내일로 넘기기**를 누르면 남은 일이 다음 근무일 할 일이 됩니다. 모두 마쳤으면 손목시계를 봅니다. |
| 점심이 끝날 때(점심 알림을 켠 경우) | 아이스 아메리카노를 행복하게 마시며 "밥 먹었으면 아아뤂! 아아 아니면 안 된뤂!" 같은 한마디를 날마다 바꿔 가며 합니다. 아아 그림(`iced`)이 오기 전에는 커피 모션으로 대신합니다. |
| 퇴근 시각 | 가방을 들고 인사하고, 말풍선의 **오늘 리포트 보기**로 퇴근 리포트를 엽니다. 설정에서 퇴근할 때 리포트를 자동으로 열 수도 있습니다. 퇴근 후 15분 이내에 깨어났을 때도 같은 인사를 한 번만 합니다. |
| 퇴근 전 마무리 알림 뒤 | "퇴근 전에 내일 할 일 미리 적어 둘까뤂?" 하고 묻고, 말풍선에서 한 줄씩 적은 할 일을 다음 근무일 할 일로 넣습니다. 퇴근 리포트의 **내일 할 일**에서도 적을 수 있습니다. 다음 날 출근하면 "오늘 할 일은 ○○, ○○ 외 n개이뤂!"처럼 오늘의 한 가지부터 브리핑하고 오늘 루틴 수도 알려 줍니다. 설정에서 끌 수 있습니다. |
| 내 루틴 | 수첩의 **내 루틴**에서 만든 루틴(시각, 근무일마다·매일·요일·몇 시간마다·오늘 한 번, 루피 동작, 한마디)을 그 시각에 말풍선으로 알려 줍니다. **같이 했어!** 또는 **10분 뒤에**로 대답합니다. 한마디의 `{호칭}`은 루피가 부르는 이름으로 바뀝니다. |
| 집중 시간(켠 경우) | 시작할 때 쉿 하고 알려 준 뒤 정각 한마디, 업무 앱 지루함, 산책 중 한마디, 내 루틴 알림을 쉬고, 끝나면 알려 줍니다. |
| 퇴근 30분 뒤에도 컴퓨터를 쓰는 중 | "설마… 야근이뤂?" 하고 묻습니다. 야근이라고 하면 "야근이라니…" 하며 옆에서 같이 타이핑하고, 한 시간마다 몇 시간째인지 말하며 그만 가자고 묻습니다. 금방 간다고 하면 20분 뒤 한 번 더, 켜 둔 거라고 하면 그날은 묻지 않습니다. 최근 3분 동안 입력이 없으면 묻지 않습니다. |
| 업무 외 시간 | 졸기 모션으로 쉬고 시간별 업무 알림은 멈춥니다. |
| 근무 중 할 일이 없을 때 | 커피, 기지개, 물, 타이핑, 서류 정리, 메모, 두리번, 아아, 낮잠 같은 동작을 혼자 번갈아 합니다(아침·점심·오후·퇴근 직전마다 고르는 동작이 다름). 수다쟁이는 25~50초, 적당히는 50~100초마다, 조용히는 6~10분마다 말없이 움직이고, 수다쟁이·적당히에서는 가끔 혼잣말도 합니다. |

| 다른 창 위에 항상 띄우기(설정 · 트레이 · 오른쪽 클릭, 기본 켜짐) | 루피와 분신이 다른 창에 가려지지 않습니다. Windows에서는 ERP처럼 스스로 맨 위에 뜨는 창이 루피를 덮어도 2초 안에 다시 위로 올라옵니다(루피 메뉴가 열려 있을 때는 메뉴를 덮지 않게 쉽니다). 끄면 보통 창처럼 쓰고 있는 창 뒤로 비켜 있다가, 올라탄 창 바로 위와 대답을 기다리는 말풍선이 떠 있는 동안에만 앞으로 나옵니다. |
| 다른 앱으로 이동 | 창에서 내려와 화면 모서리로 돌아갑니다. |
| 산책(기본 켜짐) | 화면 바닥을 따라 쉬다가 걷다가 합니다. 공중에 내려놓으면 바닥으로 떨어져 착지합니다. 말풍선이 떠 있을 때와 창 위에 앉아 있을 때는 멈추고, 업무 외 시간에는 쉬는 동안 꾸벅 좁니다. 설정의 **화면을 자유롭게 산책하기**, 루피 오른쪽 클릭 메뉴, 트레이에서 켜고 끕니다. |
| 업무 앱을 오래 붙잡고 있을 때(Windows) | 엑셀·워드·파워포인트·아웃룩, 브라우저의 구글 스프레드시트·문서·프레젠테이션·Gmail을 3분 넘게 쓰면 지루함을 한마디로 표현합니다. 수다 레벨에 따라 20분(수다쟁이)·45분(적당히)마다 최대 한 번, 같은 앱은 한 시간에 한 번이고 조용히에서는 말하지 않습니다. 같은 앱을 50분 넘게 쓰면 기지개를 권합니다. 마지막으로 말한 시각을 기억해서 다시 실행해도 바로 또 말하지 않습니다. |
| 루피를 드래그 | 집어 들면 깜짝 놀라고, 들고만 있으면 대롱대롱, 끌고 가면 가는 쪽을 보며 버둥, 마구 흔들면 어지러워하고, 올라탈 수 있는 창 윗변 위에서는 앉을 자리를 내려다봅니다. 놓은 자리에 계속 머물고 다음 실행에도 그 자리에서 시작합니다. |
| 파일 탐색기 창 윗변에 내려놓기(창 위에서 놀기를 켜 두면 엑셀 · 워드 · 파워포인트 · 한글 창도) | 그 창 위에 앉습니다. 창을 옮기면 따라가고, 다른 앱으로 가도 그 자리에 남습니다. |
| 더블클릭 / 마우스로 좌우 쓰다듬기 | 콕 찔린 반응이나 기분 좋은 반응을 하며 한마디 합니다. |
| 분신 루피(최대 5마리) | 루피 오른쪽 클릭 › 분신 루피, 트레이, 수첩 설정에서 부릅니다. 따라다니기(메인 뒤에 줄 서서 쫓아옴), 제멋대로 산책, 따라쟁이(메인 앞에서 동작을 0.5초 늦게 흉내), 낮잠꾸러기, 자동 변신(시간대에 맞춰 넷 중 하나로 알아서 바꿈, 점심엔 주로 낮잠) 중 하나로 움직입니다. 수첩 설정의 행동 설정에서 분신마다 행동 빈도(가끔 · 보통 · 자주)와 쉴 때 하는 동작(시간대에 맞게, 또는 커피 · 도장 · 만세 같은 동작을 직접 골라)을 정합니다. 분신을 누르면 반응하고, 분신을 오른쪽 클릭하면 패턴과 행동 빈도를 바꾸거나 돌려보냅니다. |
| 오른쪽 클릭 | 이야기하기, 할 일 적기, 오늘 할 일 보기, 수첩 열기, 원래 자리로 보내기, 조용히, 숨기기 메뉴가 열립니다. |

루피의 말투는 잔망루피의 말버릇을 따라 문장 끝에 '뤂'을 띄어 쓰지 않고 붙입니다("어때뤂?", "했뤂!"). 트레이에서 루피 부르기, 수첩 열기, 루피 숨기기, 한 시간 알림 쉬기, 종료를 선택할 수 있습니다. 즉시 확인하려면 수첩의 **모션**에서 원하는 동작을 누르세요.

새 모션 그림을 받으면 4칸짜리 격자 이미지를 `python scripts/import_sprites.py <격자.png> <첫째 줄 모션> [<둘째 줄 모션>]`으로 1024×256 시트로 바꾸고 `python scripts/hitmaps.py`로 클릭 영역을 다시 만듭니다.

## 두 운영체제에서의 동작

| 기능 | Windows | macOS |
|---|---|---|
| 창 인식 | Win32 탐색기 창 클래스, 오피스 · 한글은 프로그램 이름(대화 상자는 제외), DWM 경계, 모니터 배율 보정 | 앞쪽 앱의 Finder · 오피스 번들 ID와 Quartz 창 경계 |
| 다른 창 위에 띄우기 | 최상위 창으로 두고 2초마다 다시 맨 위로 올림 | floating 레벨로 둠 |
| 자동 실행 | 설치본을 처음 실행할 때 현재 사용자 로그인 시 실행을 켬(포터블은 원래 실행 파일 위치로 등록), 이후 설정에서 끄고 켬 | 설치본을 처음 실행할 때 로그인 항목을 등록, 이후 설정에서 끄고 켬 |
| 알림 | 루피 말풍선, 선택한 경우 시스템 알림 | 루피 말풍선, 선택한 경우 시스템 알림 |
| 업무 앱 알아보기 | 맨 앞 창의 프로그램 이름(엑셀·워드·파워포인트·아웃룩)과 브라우저 창 제목의 정해진 단어(Google Sheets/스프레드시트, Docs/문서, Slides/프레젠테이션, Gmail) | 아직 지원하지 않음 |

파일명·폴더명·화면 픽셀은 읽지 않습니다. **업무 앱 알아보기**를 켜면(기본 켜짐) Windows 창 감지 도우미가 맨 앞 창의 프로그램 이름을 확인하고, 브라우저일 때만 창 제목에 위의 정해진 단어가 있는지 도우미 안에서 확인한 뒤 바로 버립니다. 앱에는 '스프레드시트' 같은 종류만 전달되고, 창 제목은 저장하거나 밖으로 보내지 않습니다. **창 위에 올라타서 놀기**를 켜면 맨 앞 창이 오피스 · 한글 창인지 보려고 프로그램 이름을 확인하지만, 앱에는 그 창의 위치와 창 핸들(루피를 그 창 바로 위에 세우는 데만 씀)만 전달됩니다. 두 설정을 모두 끄면 프로그램 이름도 보지 않습니다. 일정과 할 일은 각 컴퓨터의 Electron 사용자 데이터 폴더에 저장됩니다. 두 기기에서 설정과 TODO는 각각 관리합니다. 잠금·절전·루피 숨김 상태에서는 창 추적을 멈춥니다.

모션 12종은 256×256 키프레임 48장으로 구성했습니다. `assets/motions.json`이 각 동작의 재생 순서와 프레임 유지 시간을 정의합니다. 공식 캐릭터 이미지를 참고해 만든 개인용 스프라이트입니다.
