# 루피의 업무 수첩

Windows와 macOS에서 쓰는 개인용 Electron 데스크톱 펫입니다. 루피를 클릭하면 오늘의 TODO, 모션 미리보기, 근무 설정이 열립니다. 루피 주변의 투명한 여백을 클릭하면 아래 창으로 입력이 전달됩니다.

## 실행

Node.js 22 이상을 사용합니다. Windows 개발 환경에는 .NET Framework 4 C# 컴파일러, macOS에는 Xcode Command Line Tools가 필요합니다. 설치본에는 운영체제별 창 감지 도우미가 포함됩니다.

```sh
npm install
npm test
npm start
```

Windows에서 `npm run dist:win`을 실행하면 NSIS 설치 프로그램을, Mac에서 `npm run dist:mac`을 실행하면 현재 아키텍처용 DMG를 `release/`에 만듭니다. GitHub Actions의 **Build desktop**은 Windows x64, Mac Apple Silicon, Mac Intel 패키지를 각각 만듭니다. 개인용 빌드에는 배포용 개발자 서명과 Apple 공증을 설정하지 않았습니다.

## 하루의 행동

기본 근무 시간은 월~금 09:00~18:00입니다. 설정에서 근무 요일과 출퇴근 시각을 바꿀 수 있습니다. 자정을 넘는 근무는 출근한 요일을 기준으로 계산합니다.

| 시점 또는 조작 | 루피의 행동 |
|---|---|
| 출근 후 30분 안에 첫 실행 | 오늘 적은 TODO가 없으면 수첩을 들고 “오늘 TODO는 작성 했어 룹?” 하고 묻습니다. 이미 작성했다면 손인사합니다. |
| 늦게 출근한 날 | 아침 확인을 건너뛰었다면 근무 중 다음 정각에 한 번만 TODO를 묻습니다. |
| 근무 중 매 정각 | 타이핑·커피·서류 정리·메모 동작을 바꿉니다. 지난 시간의 알림은 한꺼번에 보내지 않습니다. |
| 수첩에 할 일 추가 / 완료 | 추가할 때는 펜으로 적고, 체크하면 만세를 합니다. 완료를 취소할 수 있고 남은 일은 다음 근무일로 이월됩니다. |
| 퇴근 15분 전 | 남은 TODO 수를 알려 주며 서류를 정리합니다. 모두 마쳤으면 손목시계를 봅니다. |
| 퇴근 시각 | 가방을 들고 인사합니다. 퇴근 후 15분 이내에 깨어났을 때도 같은 인사를 한 번만 합니다. |
| 업무 외 시간 | 졸기 모션으로 쉬고 시간별 업무 알림은 멈춥니다. |
| 사용자가 Finder / 파일 탐색기에서 작업 | 활성 창 윗변을 따라 왕복하며 뜁니다. 최대화 등으로 윗공간이 좁으면 같은 창의 아랫변에 올라갑니다. |
| 다른 앱으로 이동 | 창에서 내려와 화면 모서리로 돌아갑니다. |

업무 말풍선을 누르면 수첩이 열립니다. 트레이에서 수첩 열기, 루피 숨기기, 한 시간 알림 쉬기, 종료를 선택할 수 있습니다. 즉시 확인하려면 수첩의 **모션**에서 원하는 동작을 누르세요.

## 두 운영체제에서의 동작

| 기능 | Windows | macOS |
|---|---|---|
| 창 인식 | Win32 탐색기 창 클래스와 DWM 경계, 모니터 배율 보정 | 앞쪽 앱의 Finder 번들 ID와 Quartz 창 경계 |
| 자동 실행 | 설치본 설정에서 현재 사용자 로그인 시 실행 | 설치본 설정에서 로그인 항목 등록 |
| 알림 | 루피 말풍선, 선택한 경우 시스템 알림 | 루피 말풍선, 선택한 경우 시스템 알림 |

파일명·폴더명·창 제목·화면 픽셀은 읽지 않습니다. 일정과 할 일은 각 컴퓨터의 Electron 사용자 데이터 폴더에 저장됩니다. 두 기기에서 설정과 TODO는 각각 관리합니다. 잠금·절전·루피 숨김 상태에서는 창 추적을 멈춥니다.

모션 12종은 256×256 키프레임 48장으로 구성했습니다. `assets/motions.json`이 각 동작의 재생 순서와 프레임 유지 시간을 정의합니다. 공식 캐릭터 이미지를 참고해 만든 개인용 스프라이트입니다.
